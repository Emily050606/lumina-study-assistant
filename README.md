# Lumina — AI Study Companion

A beautiful AI-powered study assistant website with a cosmic-themed design. Features a real AI chat tutor, AI-generated flashcards, a Pomodoro focus timer with ambient sounds, and a progress tracking dashboard.

## Features

- **AI Chat Tutor** — Ask any question and get real, detailed explanations from an AI study companion
- **AI Flashcard Generator** — Type any topic and instantly generate study flashcards with flip animations
- **Focus Timer** — Pomodoro-style timer with animated progress ring and real ambient soundscapes (rain, forest, ocean, cafe)
- **Progress Dashboard** — Weekly activity chart, study streak tracker, subject mastery bars, and interactive goals
- **Beautiful UI** — Glassmorphism design, animated particle background, knowledge orb visual, dark/light theme toggle

## Tech Stack

- HTML, CSS, JavaScript (vanilla — no frameworks)
- Node.js backend server
- Pollinations AI (free, no API key required) for chat and flashcard generation

## Getting Started

1. Clone the repository
2. Run the server:
   ```bash
   node server.js
   ```
3. Open `http://127.0.0.1:8092/` in your browser

## Files

- `index.html` — Main page structure
- `style.css` — Complete design system with animations
- `script.js` — All frontend interactivity
- `server.js` — Node.js backend with AI chat and flashcard API endpoints
